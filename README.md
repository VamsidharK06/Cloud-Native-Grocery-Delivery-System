# Cloud-Native Grocery Delivery System with Intelligent Budget Guardian

## Project Overview

This project combines an online grocery delivery system with an Intelligent Budget Guardian that helps users monitor and control their grocery spending.

Users can browse products, search and sort items, manage their cart, make payments, and track orders. The Intelligent Budget Guardian allows users to set a budget threshold and continuously monitors their spending.

When the cart value exceeds the specified budget, the system alerts the user. The application also tracks grocery expenses over different periods, such as the last 7 days and one month, helping users understand their spending patterns and make informed purchasing decisions.

## Problem Statement

Many users purchase groceries without properly tracking their spending and may exceed their planned budget. Existing grocery delivery applications mainly focus on product browsing, cart management, ordering, payment, and delivery, with limited support for proactive budget monitoring.

This project addresses this limitation by integrating continuous budget monitoring directly into the grocery delivery application.
